Это руководство покажет, как развернуть SFX-конвертер для вашего GDPS, используя либо [оригинальную реализацию MegaSa1nt на JavaScript](#настройка-конвертера-megasa1nt), либо [версию M336, переписанную на C#](#настройка-конвертера-m336)!

## Требования
Чтобы выполнить остальные шаги этого руководства, убедитесь, что:
- У вас есть GDPS на [форке GMDprivateServer от MegaSa1nt](https://github.com/MegaSa1nt/GMDprivateServer/tree/master)
- У вас есть устройство/сервер, способный работать 24/7
- У вас есть доменное имя, управляемое через [Cloudflare](https://www.cloudflare.com/)
- У вас стабильное интернет-соединение

## Настройка конвертера
:::tip
В Linux, чтобы приложение продолжало работать после выхода из SSH-сессии, можно воспользоваться такими решениями, как [PM2](https://pm2.keymetrics.io/docs/faq/) или [Screen](https://www.geeksforgeeks.org/linux-unix/screen-command-in-linux-with-examples/)!
:::

### Настройка конвертера MegaSa1nt
1. Скачайте [Node.js](https://nodejs.org/en/download), желательно свежую LTS-версию.
2. [Скачайте репозиторий](https://github.com/MegaSa1nt/GDPS-ConvertSFX/archive/refs/heads/main.zip) на устройство или сервер, способный работать 24/7, либо клонируйте его командой: `git clone https://github.com/MegaSa1nt/GDPS-ConvertSFX.git`.
3. Затем в его (распакованной) папке установите зависимости командой `npm install`, после чего при желании настройте [`config.json`](https://github.com/MegaSa1nt/GDPS-ConvertSFX/blob/main/config.json) под свои нужды.
4. Наконец, запустите конвертер командой `node .` из папки репозитория!

### Настройка конвертера M336
1. Скачайте подходящий для вашей системы готовый бинарный файл из [последних релизов](https://github.com/M336G/SFXConverter/releases/latest).
2. Затем в его (распакованной) папке при желании заполните файл `.env` в соответствии с вашими потребностями (пример смотрите в [.env.example](https://github.com/M336G/SFXConverter/blob/main/.env.example)).
3. Наконец, запустите конвертер, выполнив бинарный файл из распакованной папки (в Linux сначала может понадобиться сделать его исполняемым командой `chmod +x <binary_name>`).

## Открытие доступа к конвертеру из интернета через Cloudflare Tunnel
:::note
Есть несколько способов сделать конвертер общедоступным. В этом руководстве используется Cloudflare Tunnel, так как это одно из самых удобных решений.

Вы можете использовать другой способ, если хорошо с ним знакомы!
:::

:::caution
Обратите внимание: у Cloudflare Tunnel есть лимит на загрузку в 100 МБ.
:::

Чтобы люди могли пользоваться вашим конвертером из панели управления вашего GDPS, его нужно сделать доступным из интернета.

1. Откройте [панель Cloudflare](https://dash.cloudflare.com/), перейдите в **Networking > Tunnels** и нажмите **Create Tunnel**.
2. Назовите туннель, затем следуйте инструкциям по установке `cloudflared` как службы на вашем сервере.
![Создание туннеля Cloudflare](../../../../assets/gdps/self-hosting-sfx-converter/creating-cloudflare-tunnel.webp)

3. Когда туннель будет настроен, откройте его, перейдите в **Routes**, нажмите **Add route** и выберите **Published application**. Настройте маршрут так, чтобы он указывал на нужный вам URL конвертера. Затем, если вы не меняли порт конвертера, используйте `http://localhost:24157` в качестве URL службы.
![Проброс SFX-конвертера через Published application в Cloudflare](../../../../assets/gdps/self-hosting-sfx-converter/adding-published-application.webp)

4. Готово! Теперь ваш конвертер должен быть доступен из интернета.

Теперь откройте [`config/dashboard.php`](https://github.com/MegaSa1nt/GMDprivateServer/blob/67ede474cbfde8c932ede53198b743e1ffb3f3b7/config/dashboard.php#L59-L64) в установке вашего GDPS.

- **Оставить существующие конвертеры и добавить свой**, чтобы можно было использовать все.
